# Chest Item Visuals and Synergy VFX

Status: Proposed
Priority: Medium
Labels: visuals

## Summary
Define the art direction and VFX language for item chests, item pickups, and set completion bursts.

## Assigned Persona
two-d-art-director

## Problem
The mechanical feature will feel weak if the chest opening and set activation do not read clearly and feel exciting. The system needs a consistent visual identity on a mobile screen.

## Proposed Work
- Design item chest visuals and reward presentation.
- Create icon language for unique items.
- Define UI and in-world visuals for set completion.
- Add VFX for chest opening and synergy activation.
- Maintain readability and performance on mobile.

## Acceptance Criteria
- Chests have a recognizable visual identity.
- Item drops are readable at a glance.
- Set completion triggers a satisfying but readable burst effect.
- Visuals align with the existing Wizard Survivors style and readability standards.

## Dependencies
- Requires the final item and set list to be close to stable.
- Should be reviewed in tandem with the UI and balance passes.
