# Roadmap

## Short-Term (0-2 months)
- Player movement + basic enemies.
- First spell.
- XP + leveling.
- Upgrade UI.
- Element tags for all spells.
- Element count HUD and level-up previews.
- Element threshold bonuses at 2 / 4 / 6 owned instances.
- Basic wave system.
- First arena.

## Mid-Term (2-6 months)
- 10+ spells.
- 20+ upgrades.
- 5+ enemy types.
- Meta progression.
- Save system.
- Character unlocks.

## Long-Term (6+ months)
- Multiple arenas.
- Boss fights.
- Mobile port.
- Steam release.
